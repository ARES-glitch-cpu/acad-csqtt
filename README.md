# CSQTT Desktop 1.4.1

Настольный клиент CSQTT для **Windows и Linux**. Основа приложения — Wails v2, Go и Svelte/TypeScript; сетевые операции выполняет существующее Rust-ядро и локальный помощник.

## Возможности

- Подключение в режимах системного TUN и локальных SOCKS5/HTTP прокси.
- Корпоративный HTTP CONNECT, прямой выход в интернет, ручной выбор TURN UDP/TCP.
- SRTP: AUTO, WRAP-SRTP и DTLS-SRTP; TLS Client fingerprint и Client IDs.
- Встроенный Gooby для прямого TURN TCP/TLS, со стратегиями current, gentle и extended. Gooby не работает с UDP и корпоративным HTTP CONNECT.
- Пять TURN-подсетей VK из Android CSQTTTR 2.5.3, ограничение числа IP-кандидатов (1, 2, 4, 9 или все). Пустой выбор использует адреса из ответа VK; собственный список имеет приоритет.
- Доменные правила и IPv4-правила с чёрными/белыми списками, CIDR, диапазонами, шаблонными доменами и исключением RU/SU/РФ. Они применяются в системном TUN.
- Журнал ядра, статистика трафика, локальные адреса, проверка интернета и обновлений.
- SSH-проверка и обслуживание VPS: read-only inventory, pinning SSH host key, проверка SHA-256 серверных бинарников, установка/обновление/переустановка/удаление только по подтверждённому плану.

## Установка и запуск

Скачайте архив Windows или Linux из Releases и распакуйте его полностью. Не запускайте один EXE/бинарник отдельно от каталогов и файлов, входящих в архив.

На Windows запускайте `CSQTT.exe`. Для системного TUN запрашиваются права администратора; в архив входит Wintun для Windows x64.

На Linux запускайте `CSQTT` из распакованного архива. Для системного TUN нужны права root либо `pkexec`/polkit. Для системного трея требуется активная StatusNotifier/AppIndicator-среда рабочего стола; если в минимальном оконном менеджере такой среды нет, приложение сообщит о недоступности трея.

Кнопка сворачивания, крестик и минимизация прячут окно в системный трей, не отключая туннель. Пункт «Открыть CSQTT» восстанавливает окно; «Выход» полностью останавливает сетевые процессы и закрывает приложение.

## Интерфейс и настройки

Интерфейс переработан в новую настольную панель управления: обзор соединения, настройки, деплой, маршрутизация и журнал. Тема — тёмная с адаптивной раскладкой, отдельной статистикой и карточками быстрого управления.

В настройках доступны профиль администратора/клиента, сервер и хеши, корпоративный прокси, локальные порты, транспорт TURN, SRTP, Gooby, TLS fingerprint, Client IDs, CAPTCHA mode, TURN-IP и DNS. Режим VK авторизации в этой сборке ограничен поддерживаемым `vkcalls`; интерактивный Android Auto-JS/WebView OAuth-поток пока не перенесён.

### Хранение конфигурации

Все изменения автоматически сохраняются в отдельный пользовательский файл:

- Windows: `%APPDATA%\CSQTT\config.json`. Пароли, ключи, хеши и другие секретные поля защищаются DPAPI для текущей учётной записи Windows.
- Linux: `$XDG_CONFIG_HOME/CSQTT/config.json` или `~/.config/CSQTT/config.json`. Каталог создаётся с правами `700`, файл — `600`; значения секретных полей хранятся в JSON открытым текстом, но доступны только владельцу файла.

Старый `profile.json` из папки приложения автоматически мигрирует в пользовательский `config.json`. На Windows секреты мигрированного профиля шифруются DPAPI при первом сохранении. При отключении запоминания текущий конфиг и старый локальный профиль удаляются.

При переносе на другой компьютер можно перенести Linux JSON, но он содержит секреты в открытом виде. Windows DPAPI-поля привязаны к текущей Windows-учётной записи и не расшифруются на другом компьютере/под другим пользователем автоматически.

## Деплой VPS

В разделе «Деплой» задаются SSH-адрес, порт, пользователь, пароль или приватный ключ, порты сервера и параметры веб-панели.

Первичная проверка выполняет только read-only инвентаризацию. Неизвестный или изменившийся SSH host key не принимается автоматически: нужно независимо сверить SHA-256 fingerprint на VPS и явно подтвердить именно показанный ключ. После этого приложение повторно читает инвентаризацию и предлагает только разрешённые для обнаруженной конфигурации действия.

Серверный бинарник выбирается по архитектуре VPS и перед загрузкой проверяется по размеру, SHA-256 и provenance-манифесту. Удаление и переустановка требуют дополнительного ввода фразы `УДАЛИТЬ CSQTT`. Не используйте эти действия без резервной копии данных VPS.

## Ограничения настольной версии

Некоторые Android-функции привязаны к мобильной платформе и не переносятся буквально:

- Android per-app VPN routing заменён на доменные и IPv4-правила системного TUN; список установленных Android-приложений отсутствует.
- Сканирование SSID и Android Wi-Fi auto-pause/allowlist не перенесены в данный выпуск.
- Android Battery Saver/PowerManager не имеет прямого аналога в desktop UI.
- Android VK Auto-JS/WebView и управление VK-токенами не перенесены; доступен режим `vkcalls`.
- Android foreground service, разрешения VPN и мобильные уведомления заменены средствами Windows/Linux и системным треем.

## Сборка

Требуются Go, Node.js, Wails CLI и Rust toolchain версии, указанные в CI и `rust-toolchain.toml`. Linux-сборка дополнительно использует GTK/WebKit и AppIndicator/StatusNotifier зависимости; Windows-сборка использует WebView2 и MSVC Build Tools.

Проверки в CI выполняют Go tests, Svelte build, Rust tests и portable packaging для Windows/Linux. Release публикуется только после успешных сборок.

## Архитектура

- `frontend/` — Svelte/TypeScript UI и стили.
- `app.go`, `main.go`, `deploy.go` — Wails API, жизненный цикл, системный трей и SSH-деплой.
- `internal/client/` — профиль, config.json, DPAPI, менеджер сетевых процессов и проверки сети.
- `internal/tray/` — нативный Windows tray и Linux AppIndicator/StatusNotifier tray.
- `core/rust-client/` — Rust-клиент, TURN, SRTP, Gooby и маршрутизация.
- `packet-proxy/` — локальные SOCKS5/HTTP и TUN-помощник.
- `assets/deploy.sh`, `assets/server-downloads.json`, `assets/csqtt.server-provenance.json` — проверенный комплект серверного деплоя из Android CSQTTTR 2.5.3.
