CSQTT 1.4.1 — обновлена оболочка Windows на основе but-rr/acad-csqtt v1.4.1.

- Полностью заменён интерфейс на Wails v2 + Svelte: экран подключения, навигация, статистика, настройки, журнал, системный трей и диалог обновления.
- Добавлен графический переключатель ролей «Администратор / Клиент».
- Администратор вводит серверные параметры вручную; клиент подключается по ссылке csqtt:// и может задать пароль отдельно.
- В настройках туннеля добавлено видимое поле DNS IPv4: один или несколько адресов через запятую; значение сохраняется в profile.json и передаётся сетевому помощнику.
- Сетевое ядро CSQTT и packet-proxy сохранены из текущего проекта; DNS override использует существующую поддержку DNS-адресов в TUN-помощнике.
- Обновлена метка версии приложения до 1.4.1.
